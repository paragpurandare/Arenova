# 🏆 Arenova -Unified Sports Arena, Rental & Player Experience Platform 

A production-ready Sports Club Management System built using Spring Boot 3.x following a Modular Monolithic Architecture with a future migration path to Microservices.

## 🚀 Tech Stack

- Java 21
- Spring Boot 3.x
- Maven
- MySQL
- Spring Data JPA (Hibernate)
- Spring Security
- JWT Authentication
- Spring Validation
- Lombok
- ModelMapper
- Swagger / OpenAPI


## 🏗️ Architecture

- Modular Monolithic Architecture
- Layered Architecture
- RESTful APIs
- DTO Pattern
- Global Exception Handling
- Common API Response Structure
- Role-Based Access Control (RBAC)


## 🔮 Future Enhancements

- Microservices Architecture
- API Gateway
- Service Discovery
- Redis
- Kafka / RabbitMQ
- Docker
- Jenkins CI/CD


## 🛠️ Build Tool

- Maven

## 💾 Database

- MySQL
